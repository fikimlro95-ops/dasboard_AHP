Tahapan metode

Sintesis prioritas dan uji konsistensi.

Prioritas lokal
PV = eigenvector utama dari matriks A
Lambda maksimum
λmax = rata-rata((A × w)i / wi)
Consistency Index
CI = (λmax - n) / (n - 1)
Consistency Ratio
CR = CI / RI

Matriks perbandingan berpasangan memakai skala Saaty 1–9 dan nilai kebalikannya. Bobot global alternatif dihitung dari penjumlahan bobot kriteria dikalikan prioritas lokal alternatif. Penilaian dinyatakan konsisten bila CR < 0.10. Untuk n = 3, nilai Random Index (RI) = 0.58.

CR keseluruhan pada data tugas adalah 0.0158, sehingga perbandingan memenuhi batas konsistensi.
